\begin{abstract}
We compare four numerical methods for the Merton portfolio problem using equity parameters estimated from Apple adjusted closing prices: a log-wealth finite-difference grid, two value-network formulations, and a forward deep BSDE. The sample covers 23~May~2023 through 22~May~2026 and contains 752 daily log returns. The annualized mean log return is $m=0.201649$, and the estimated GBM volatility is $\sigma=0.256573$. Accordingly, the drift in $\mathrm dS/S$ is $\mu=m+\sigma^2/2=0.234564$, rather than $m$. With constant risk-free rate $r=0.0368$, relative risk aversion $\gamma=5$, and no intermediate consumption, the classical Merton allocation is $\pi^{\star}=0.600837$.

On a shared evaluation mesh of $10^{4}$ points, the $500\times 252$ log-wealth grid achieves a policy mean absolute error (MAE) of $2.52\times 10^{-4}$. Across five runs, the power-scaled value network, whose free function $g(t,\log w)$ multiplies the CRRA profile, has policy MAE $1.62\times 10^{-3}$ (sample standard deviation $5.8\times 10^{-4}$) and value MAE $7.09\times 10^{-4}$. The more restrictive ansatz $g=g(t)$ recovers the optimal weight to round-off; its mean value error is $4.64\times 10^{-4}$. Across five runs, the forward deep BSDE has policy MAE $0.0215$ (standard deviation $0.0072$), while its estimate of $V(0,1)$ differs from the closed-form value by about $5\times 10^{-5}$. On $20{,}000$ shared paths, the certainty equivalent for each one-dimensional method is within $10^{-4}$ of the closed-form value, $1.10105$. Adding an Ornstein--Uhlenbeck factor correlated with the stock lowers the grid weight at $(t,Y)=(0,0)$ from $0.601$ to $0.499$. The power-scaled network has policy error $0.018$ against this factor grid, compared with about $0.097$ for the deep BSDE. Under the constraint $0\le\pi\le0.4$, the grid's weight differs from $\pi^{\star}$ by $0.201$ on average, and the network matches the constrained grid to $10^{-8}$. All reported values are taken from the run ledger; the experiment driver is \texttt{run\_one.py}.
\end{abstract}

\noindent\textbf{Keywords:} Merton problem; GBM drift; finite differences; physics-informed neural networks; deep BSDE.

\section{Scope and contributions}
\label{sec:claim}

This paper presents a controlled numerical comparison; it does not establish a new theorem or make claims about problems at dimension $d=100$. The control problem follows \citet{merton1969} and \citet{merton1971}. The value-network approaches draw on \citet{raissi2019} and \citet{sirignano2018}. We cite \citet{e2017} and \citet{han2018} for the forward discretization, but train the terminal-loss objective $\E[(Y_T-U(W_T))^2]-\E[U(W_T)]$, not the distinct martingale objective $-\E[Y_0]+\mathrm{Var}(Y_0)$.

We apply the GBM drift correction before training and report five independently seeded runs for each one-dimensional network under a prespecified budget. We also examine finite-difference convergence as the wealth grid is refined. Because the CRRA-shaped ansatz implies the optimal policy analytically, we treat it as a value-function approximation rather than evidence of policy learning. Following the stochastic-opportunity-set setting of \citet{kim1996}, we solve a one-factor problem on a $(t,Y)$ grid: CRRA homogeneity separates wealth, while the correlated factor remains a state variable. We evaluate the binding leverage constraint against the constrained grid rather than the unconstrained Merton weight.

The study does not propose a high-dimensional solver or an existence result for a consumption--investment problem. Nor does the small policy error of the CRRA ansatz show that a network has learned the optimal allocation. The risk-free rate is held fixed, and the empirical calibration uses a single equity.

\section{Market inputs and calibration}
\label{sec:market}

Let $S_t$ denote Apple's adjusted closing price. The 753 trading sessions from 23~May~2023 through 22~May~2026 yield $n=752$ daily log returns for AAPL, obtained using \texttt{yfinance}. Using 252 trading days per year,
\begin{align}
m &= 252\cdot \frac{1}{n}\sum_{i=1}^{n}\log\frac{S_{i}}{S_{i-1}} = 0.20164940530246397,\\
\sigma &= \sqrt{252}\; s_{n-1}(\log S_{i}/S_{i-1}) = 0.2565727586666484.
\end{align}
If $\mathrm dS/S=\mu\,\mathrm dt+\sigma\,\mathrm dB$, then $\E[\log(S_{t+\Delta}/S_t)]=(\mu-\sigma^2/2)\Delta t$, so the drift that enters the wealth equation is
\begin{equation}
\mu = m+\sigma^2/2 = 0.23456419554737107.
\end{equation}
An independent \texttt{yfinance} download for the same period reproduced $m$ and $\sigma$ to within $10^{-7}$. The experiments use the frozen estimates reported above. The risk-free rate $r=0.0368$ is a specified constant, not an estimate of the Treasury-bill rate. We set relative risk aversion to $\gamma=5$, the horizon to $T=1$, and initial wealth to $W_0=1$. No intermediate consumption is included in the one-dimensional model.

\section{The Merton portfolio problem}
\label{sec:control}

Wealth invested in the risky asset and the money-market account evolves according tos
\begin{equation}
\mathrm dW_t = W_t\big(r+\pi_t(\mu-r)\big)\,\mathrm dt + W_t\pi_t\sigma\,\mathrm dB_t,
\end{equation}
The investor maximizes expected terminal utility, $\E[U(W_T)]$, where
\begin{equation}
U(w)=\frac{w^{1-\gamma}}{1-\gamma}, \qquad \gamma>1.
\end{equation}
The value function $V(t,w)$ satisfies the Hamilton--Jacobi--Bellman equation derived in \citet{merton1969},
\begin{equation}
V_t + \sup_{\pi}\Big\{w\big(r+\pi(\mu-r)\big)V_w + \tfrac12 \pi^2\sigma^2 w^2 V_{ww}\Big\} = 0,
\end{equation}
subject to $V(T,w)=U(w)$. The optimal allocation and value function are
\begin{align}
\pi^{\star} &= \frac{\mu-r}{\gamma\sigma^2},\\
V(t,w) &= \mathrm e^{A(T-t)}\frac{w^{1-\gamma}}{1-\gamma},\\
A &= (1-\gamma)\left(r+\frac{(\mu-r)^2}{2\gamma\sigma^2}\right).
\end{align}
For the frozen coefficients, $\pi^{\star}=0.600836870221195$ and $V(0,1)=-0.170138511234813$.

\section{Numerical methods}
\label{sec:methods}

\subsection{Finite differences}

We discretize the PDE in log wealth, $x=\log w$, over $x\in[-2.5,4.5]$. Time stepping is fully implicit ($\theta=1$), and we use an upwind approximation for the advection term. At each grid node, we compute the candidate control from the first-order condition
\begin{equation}
\pi = -\frac{(\mu-r)V_x}{\sigma^2(V_{xx}-V_x)}.
\end{equation}
We then project it onto the admissible interval: $[-1,5]$ in the unconstrained experiments and $[0,0.4]$ in the constrained experiments. Non-finite first-order conditions are set to zero; the analytical weight $\pi^{\star}$ is never inserted. The reference grid for the main tables has $N_x=500$ wealth points and $N_t=252$ time steps.

\subsection{Collocation and the terminal condition}

At each Adam iteration, both value networks draw a fresh Latin-hypercube sample. Interior collocation points are sampled jointly in time and wealth, with time uniform on $[0,T]$ and wealth uniform on $[0.5,2]$. Each one-dimensional run uses $25{,}000$ interior points. The terminal-condition loss uses $8{,}000$ wealth samples from the same interval, with time fixed at $T$ and target $U(w)$. The sampler seed is determined by the run seed and epoch, so repeating a command with the same seed reproduces the minibatches on the same device type.

Following the collocation approach of \citet{raissi2019}, we use a network with a power head that scales its output to the utility function. Five hyperbolic-tangent layers, each of width 128, map $(\log w,t)$ to a scalar $g$. We define the value function as
\begin{equation}
V(t,w)=\mathrm e^{g(t,\log w)}\frac{w^{1-\gamma}}{1-\gamma}.
\end{equation}
Because $g$ can depend on wealth, this architecture does not impose $V_w/(wV_{ww})=1/\gamma$. The network does not output a policy directly; after training, we recover the weight by applying the first-order condition to automatic derivatives of $V$. The loss combines the mean-square HJB residual, ten times the relative terminal mismatch, and penalties equal to $0.1$ times the squared positive parts of $V_{ww}$ and $-V_w$. For unconstrained runs, the residual uses the reduced Hamiltonian. For capped runs, it evaluates the Hamiltonian at the control projected onto $[0,0.4]$. We did not use an unscaled output network because target values span several orders of magnitude over the wealth interval $[0.5,2]$. The power head addresses this scale variation without imposing $\pi^{\star}$.

\subsection{The CRRA ansatz}

The CRRA-shaped network is defined by
\begin{equation}
V(t,w)=\mathrm e^{g_\theta(t)}\frac{w^{1-\gamma}}{1-\gamma}.
\end{equation}
For any $g_\theta$, the ratio $V_w/(wV_{ww})$ equals $1/\gamma$. Thus, when the training coefficients match the evaluation coefficients, the recovered weight equals $\pi^{\star}$ up to machine precision. A policy error of approximately $10^{-8}$ therefore checks the automatic derivatives; it does not measure policy learning. The network trains the scalar function $g_\theta$, and we report its value-function error.

\subsection{Forward deep BSDE}

Our scheme uses the forward discretization described by \citet{han2018} and \citet{e2017}. We evolve a scalar initial value $Y_0$ and a network $Z$ alongside controlled wealth; the model has no intermediate consumption. Under a Markov control that satisfies the HJB equation, the value process is a martingale, giving the update
\begin{equation}
Y \leftarrow Y + Z(t,W)\,\Delta B.
\end{equation}
We evaluate $Z$ at the wealth value before applying the current Brownian increment. The policy network affects the state evolution through the wealth process $W$, and a $2\tanh$ transformation restricts its output to $(-2,2)$. Each training batch contains $1{,}024$ paths with $64$ time steps, and the loss is
\begin{equation}
\E\big[(Y_T-U(W_T))^2\big] - \E[U(W_T)].
\end{equation}
The mean-square term trains $(Y_0,Z)$, while the expected-utility term guides policy optimization. A flexible $Z$ can fit the terminal condition even when the control is poor, so terminal matching alone is insufficient. We initialize $Y_0$ at $U(W_0)$ rather than at its closed-form value. This terminal-loss objective differs from the martingale approach, which imposes $Y_T=U(W_T)$ and minimizes $-\E[Y_0]+\mathrm{Var}(Y_0)$.

\subsection{Training and evaluation protocol}

We train each one-dimensional network for $2{,}000$ epochs using Adam with learning rate $10^{-3}$ and retain the checkpoint with the lowest training loss. The power-scaled network, CRRA ansatz, and deep BSDE each use seeds $\{0,1,2,3,4\}$. We evaluate all one-dimensional methods on the same $10^{4}$-point mesh (seed $12345$), with log-uniform wealth on $[0.5,2]$ and uniform time on $[0,1)$. Traded utility is estimated on the same $20{,}000$ paths for every method, using $252$ steps and seed $7$. Certainty-equivalent wealth is defined by $U(w)=\E[U(W_T)]$. Training used CUDA; CPU runs may differ slightly in floating-point values, but the seeds and grid acceptance threshold are unchanged.

\section{Results for the constant-coefficient problem}
\label{sec:results1d}

\subsection{Finite-difference grid}

Experiment E1 uses the corrected drift $\mu$ on a grid with 500 wealth points and 252 time steps. On the shared evaluation mesh, the policy MAE is $2.5217\times 10^{-4}$. The near equality of the root-mean-square and mean absolute errors indicates that the grid's small policy bias is nearly constant across the mesh, as expected when the optimal weight itself is constant. At the grid node nearest $(t,W)=(0,1)$, the computed value is $-0.169453$, compared with the exact value $-0.170139$. The value-function MAE over the mesh is $4.398\times 10^{-3}$. On the common paths, both the closed-form and grid policies yield certainty-equivalent wealth of $1.10105$ to five decimal places; their mean utility is $-0.170103$.

\subsection{CRRA ansatz: five-seed results}

In E4, we train the time-only CRRA ansatz for $2{,}000$ epochs. Across seeds, policy MAE ranges from $3.18\times 10^{-8}$ to $3.26\times 10^{-8}$. This near-zero error reflects the architecture's analytical structure and serves as a derivative check, rather than an independent measure of policy performance. Across five seeds, value MAE averages $4.64\times 10^{-4}$, with sample standard deviation $1.81\times 10^{-4}$. The individual value errors are $4.61$, $3.02$, $6.42$, $6.49$, and $2.66$, each in units of $10^{-4}$. On the shared paths, the ansatz yields the same certainty equivalent as the closed-form policy, $1.10105$, as expected when both use $\pi^{\star}$.

\subsection{Power-scaled value network}

Experiment E3 trains the network $V=\mathrm e^{g(t,\log w)}w^{1-\gamma}/(1-\gamma)$ for $2{,}000$ epochs using five seeds, $25{,}000$ collocation points, and $8{,}000$ terminal points. \section{Stochastic investment opportunity set}
\label{sec:factor}

With constant coefficients, CRRA homogeneity reduces the problem to a PDE with one spatial state variable. Adding another risky asset with constant coefficients would not introduce a state-dependent investment opportunity set, so we instead add a stochastic factor, following the setting of \citet{kim1996}. Let the factor satisfy the Ornstein--Uhlenbeck equation
\begin{equation}
\mathrm dY_t = -\kappa Y_t\,\mathrm dt + \nu\,\mathrm dB^Y_t,
\end{equation}
with $\kappa=1.2$, $\nu=0.30$, and $\mathrm{Corr}(\mathrm dB,\mathrm dB^Y)=\rho=0.45$. The stock drift is $\mu+\phi Y$, where $\phi=0.20$. The value function still separates in wealth,
\begin{equation}
V(t,w,y)=f(t,y)\frac{w^{1-\gamma}}{1-\gamma},
\end{equation}
although the optimal allocation now includes a hedging demand:
\begin{equation}
\pi^{\star}(t,y)=\frac{\mu+\phi y-r}{\gamma\sigma^2}+\frac{\rho\nu}{\sigma\gamma}\frac{f_y}{f}.
\end{equation}
The function $f$ varies with $y$ and is computed on a grid of 81 factor nodes over $[-1.5,1.5]$ and 200 time steps. The policy is lagged by one time level in the linear implicit step, and Neumann boundary conditions are imposed at both factor-domain endpoints. As a validation, setting $\phi=0$ and $\rho=0$ recovers $\mathrm e^{AT}$ with maximum absolute error $2.52\times 10^{-4}$. This check confirms that the factor solver reproduces the constant-opportunity benchmark without inserting its solution.

The factor PINN represents $f$ as $f=\mathrm e^{g(t,y)}$, using $4{,}096$ Latin-hypercube collocation points and a terminal penalty enforcing $g(T,y)=0$. The factor BSDE uses two Brownian increments and evaluates both components of $Z$ before updating the state; its objective is the same terminal-loss-plus-utility objective. Experiments E7 and E8 use seeds 0 and 1, respectively, and train for 800 epochs. Both methods are evaluated against the factor grid on $4{,}000$ points, rather than against the constant-coefficient weight $\pi^{\star}$.

Using the Apple calibration, the factor grid gives $\pi(0,0)=0.49918$ and $V(0,1,0)=-0.16217$. For comparison, the corresponding constant-opportunity values are $0.60084$ and $-0.17014$. The change in allocation reflects both the state-dependent drift and the hedging demand; the optimal weight is no longer constant.

For E7 and E8, the factor network and two-noise deep BSDE are each trained for 800 epochs. The power-scaled network's policy MAEs against the factor grid are $0.01810$ (seed 0) and $0.01861$ (seed 1); the corresponding value MAEs are $0.0437$ and $0.0451$. The deep BSDE policy MAEs are $0.0949$ and $0.0994$. Its initial value estimate is approximately $-0.1717$, compared with the grid value $-0.1622$ at $(W,Y)=(1,0)$, a difference of $9.6\times 10^{-3}$. In this experiment, the power-scaled network has lower reported policy error than the deep BSDE. \Cref{fig:factor} shows the grid policy over $(t,Y)$.

\section{Results under a binding portfolio constraint}
\label{sec:cap}

The unconstrained Merton weight is approximately $0.60$, so the interval $[0,1]$ does not bind. Experiments E9 and E10 instead impose the tighter constraint $\pi\in[0,0.4]$. With constant coefficients, the constrained optimum is the projection of $\pi^{\star}$ onto this interval. We use the finite-difference solution under the same constraint as the network's reference. The power-scaled value network is trained for $2{,}000$ epochs with seeds 0 and 1, and the Hamiltonian is evaluated at the projected control. A network that returned the unconstrained weight $\pi^{\star}$ would therefore be incorrect.

Experiments E9 and E10 use a $400\times 200$ grid and network seeds 0 and 1. On the shared mesh, the constrained grid's policy differs from the unconstrained $\pi^{\star}$ by MAE $0.200837$, equal to $\pi^{\star}-0.4$ because the upper bound binds throughout. The power-scaled network reproduces the constrained grid policy to within $6.0\times 10^{-9}$ for both seeds. Its value MAEs against the grid are $4.12\times 10^{-3}$ (seed 0) and $4.15\times 10^{-3}$ (seed 1). At the grid node nearest $(t,W)=(0,1)$, the constrained value is $-0.166096$, greater (less negative) than the unconstrained value $-0.170139$. This increase reflects the value of the leverage excluded by the cap. The network does not return the unconstrained weight.

\section{Reproducibility}
\label{sec:repro}

Code and run artifacts are available in the companion GitHub repository. The repository's \texttt{README.md} describes the environment and provides instructions for reproducing experiments E1--E10, regenerating the figures, and building this PDF. Experiment E1 stops if policy MAE exceeds $2\times10^{-3}$ or if the absolute error in $V(0,1)$ exceeds $5\times10^{-3}$. The sample standard deviations reported in \Cref{tab:main1d} are listed in \texttt{results/v2/figures/table\_main.csv}: $5.79\times10^{-4}$ for the power-scaled policy and $7.20\times10^{-3}$ for the deep BSDE policy.

\section{Limitations and scope}
\label{sec:limits}

The risk-free rate is held fixed rather than estimated from the price data. The calibration uses one equity, and the factor extension has only one additional state; neither experiment tests a genuinely high-dimensional problem. Because the CRRA ansatz imposes the constant-coefficient policy by construction, its small policy error does not show that a general value network has learned the optimal allocation. The deep BSDE is trained with 64 time steps but evaluated using wealth paths simulated with 252 steps, so its initial-value estimate $Y_0$ need not coincide with the utility estimate from the trading simulation. Finally, the constrained constant-coefficient problem has a closed-form projection solution. We include the grid as a benchmark for future constraints without such an explicit solution and to avoid supplying $\pi^{\star}$ to the network.
